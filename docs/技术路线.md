# 技术路线 · 边缘感知推理优化

> 本文只记录项目的技术方法论与学习资源，不涉及任何个人发展规划。

## 落点方向

以「端到端模型部署 / 推理优化」为技术落点，建立跨平台的异构计算思维模型：
**latency / 吞吐 / 精度 / 显存** 指标自持，问题在自己手里定位并解决（闭环）。

## 核心方法论

学架构参考 MindSDK，用底层 ACL 手写实现。目标是理解异构计算流水线的通用结构，而非绑定某一家 Runtime API。

## ⑤ 的执行原则：MindSDK 写法 → 底层 ACL 实现

| 流水线环节 | MindSDK 的写法（参考） | 本项目实现（底层 API） |
|-----------|----------------------|---------------------|
| 图片解码 | `ImageProcessor::Decode()` | 先用 OpenCV `imread()`，后续对比 DVPP 延时 |
| Device 内存分配 | `MemoryHelper::MxbsMalloc()` | `aclrtMalloc()` |
| Host↔Device 拷贝 | `MemoryHelper::MxbsMallocAndCopy()` | `aclrtMemcpy()` |
| 模型推理 | `Model::Infer()` | `aclmdlLoadFromFile()` + `aclmdlExecute()` |
| 结果回传 | `Tensor.ToHost()` | `aclrtMemcpy()` D2H |
| Stream 同步 | `stream.Synchronize()` | `aclrtStreamSynchronize()` |

## 技术铁律

1. **每周至少 commit 一次代码**，保持进度可追溯。
2. **先跑代码后读论文**，跑不通的论文不值得深读。
3. **每做一件事先问：这是闭环，还是只是传递？** 只在能自己闭环的事上投入。
