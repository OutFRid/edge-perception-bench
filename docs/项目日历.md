> 2026-11-01 进展：连板补做 **R4 + R5**（两志：`docs/weekly/2026-10-25_R4-profiling基线.md`、`docs/weekly/2026-11-01_R5-INT8量化.md`）。**R4** 用板端 `msprof` 把 yolov8n 下钻到 device 逐层口径：单次前向 105 个 AI-core 任务 / 总 11.9ms（≈ bench compute 13ms，交叉验证）；**Conv2D 占 59%**，但纯搬数(mac+vec=3.5ms) < 纯访存(mte1/2/3+fixpipe=5.7ms) → **310B 上 yolov8n 是访存/搬运 bound**；NPU 显存 1681→1688MiB（单路增量仅 ~7MiB）。产物 `results/doc/r4_prof/`。**R5** 走 WSL onnxruntime QDQ 静态量化 yolov8n FP32→INT8（12.2→3.4MB）：精度近无损（输出 cosine 0.999、person conf −0.021、匹配框 IoU 0.895），但 **CPU 口径 INT8 反而慢 1.3×**（ORT 无 x86 融合 int8 kernel）→ 量化收益是硬件属性。**遇阻**：ATC 不解析通用 QDQ ONNX、toolkit 无 AMCT/msct 离线量化 CLI → **真·NPU INT8 OM 本周无法上板**，其延时收益/上板 mAP 顺延 R6/缓冲周（不粉饰为已达标）。R1 前置学习③（DVPP 精读）正式并入 R7。
